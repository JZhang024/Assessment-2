# Assessment-2
# Project Title
Labour and Trust Analysis Dashboard

# Project Overview
This project explores the relationship between labour underutilisation rates and trust in government, employing dynamic data collection, data cleaning, and visualization techniques. It further develops an interactive dashboard using R Shiny for in-depth data exploration. Key components of this project include:
1. Dynamic web scraping
2. Data cleaning and feature analysis
3. Development of an interactive visualization dashboard with R Shiny
4. Utilization of ChatGPT for code optimization and technical support

# Data Source
The dataset was sourced from the OECD Data Explorer 

[OECD link]{https://data-explorer.oecd.org/vis?lc=en&tm=DF_HSL_FWB&pg=0&snb=1&vw=tb&df[ds]=dsDisseminateFinalDMZ&df[id]=DSD_HSL%40DF_HSL_FWB&df[ag]=OECD.WISE.WDP&df[vs]=&pd=2019%2C2019&dq=..._T._T._T.&to[TIME_PERIOD]=false}

The dataset encompasses 41 countries and various indicators across social, economic, human, and natural capital domains. Two key indicators were selected for analysis:
1. Labour Underutilisation Rate: A measure of inefficiencies in the labour market.
2. Trust in Government: Reflects public confidence in government institutions.

# Dashboard Features
1. Scatter Plot: Illustrates the relationship between trust in government and labour underutilisation rates.
2. Bar Chart: Compares labour underutilisation rates across countries.
3. Histogram: Displays the distribution of trust in government levels.

# Collaboration with ChatGPT
ChatGPT was employed in this project for:
1. Code Optimization: Suggestions for dynamic scrolling and data cleaning processes.
2. Debugging Support: Assistance in resolving common coding errors.
